# Filing rules (SOP: E-Filing, Paper Filing Returns, E-File Rejects, Superseded/Amended, Extension Prep)

## Due dates (TY2025)
* Form 1040 and most states: 04/15/2026; with Form 4868 extension: 10/15/2026 (extension extends filing, not payment - interest
  runs on any balance after 04/15).
* FBAR (FinCEN 114): 04/15/2026, automatic extension to 10/15/2026; filed with FinCEN (BSA E-Filing), not with the 1040.
* Form 3520: due with the 1040 (incl. extension); **filed separately by mail** (IRS, Ogden UT) - cannot be e-filed.
* Form 8938, 8621, 5471, 8865, 8858: attached to the 1040.
* 2026 Form 1040-ES: 04/15, 06/15, 09/15/2026, 01/15/2027.
* Late Forms 1099-NEC / W-2 (household employee): file ASAP; penalties scale with lateness.
* City returns: Detroit/Grand Rapids follow 04/30 or 04/15 patterns - state the city's date and flag "verify".

## E-file vs paper (SOP: Paper Filing Returns)
E-file by default. Paper when:
* The software can't produce a required form for e-file (e.g. ProConnect: Form 8865; 1042-S withholding on a 1040).
* Persistent/uncorrectable e-file rejects; dependent already claimed on another return (IND-507 type reject) when your client
  is entitled - paper file with documentation.
* Tax years outside the e-file window; anything due during the IRS blackout window.
* Unresolvable name-control/SSN mismatch (fix with SSA if possible - name on return must match SSA records).
Paper package: government copy, mailing label to the correct service center, tracked delivery.

## E-file blockers to check (SOP: E-File Rejects)
* IP PIN: required if the taxpayer (or spouse/dependent) was issued one - it changes every year; a prior-year IP PIN letter
  in the file is NOT valid for 2025 returns. Retrieve the current one (IRS online account).
* Name control: last name as on the SSA record (recent marriages!).
* Self-select PIN / Form 8879 signed; prior-year AGI if needed; driver's license data.
* Required PDF attachments (8949 detail statement, elections, 7203, 8082, 1033 election statement).
* 24-hour hold after client approval before transmitting (SOP).

## Superseded vs amended
* Superseded: refiled after acceptance but before the extended due date - treated as the original.
* Amended (1040-X): after the extended due date. Recommend when prior-year errors are found (e.g. missed FBARs - separate
  engagement; consider delinquent-filing procedures).

## Billing (SOP: Billing)
* Two-column invoice (Description, $ Amount), list forms prepared. Internal errors -> write off; client-caused extra work
  (late/incorrect documents) -> chargeable. Documents received within 15 days of a deadline -> 15% expedite fee if the client
  wants the deadline met.
